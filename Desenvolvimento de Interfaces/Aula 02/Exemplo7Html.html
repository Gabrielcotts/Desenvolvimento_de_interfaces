Exemplo 7 - HTML - Listas

Em documentos html podemos usar 3 listas distintas, são elas: lista ordenada, lista não ordenada e lista descritiva. Essas listas são representadas pelas tags: <ol>, <ul> e dt/d1/dd. Para todas as listas, utilizamos a tag <li>, que representa um item e só pode ser utilizada dentro das listas ordenadas ou não ordenadas

Lista ordenada - <ol>

Neste tipo de lista os elementos são distribuídos em ordem, ou seja, a ordem importa. Por exemplo:

  1. Planejamento
  2. Design
  3. Desenvolvimento
  4. Testes
  5. Publicação

Lista não ordenada - <ul>

Esse tipo de lista não possui uma ordem específica e seus elementos são representados por bullets. Essa lista é muito utilizada para a construção de menus. Por exemplo:

  • HTML
  • CSS
  • JavaScripts
  • Outras tecnologias

Listas aninhadas

Nesse tipo de lista possuímos sublistas, conforme exemplificamos abaixo:

  2. Design

  3. Desenvolvimento

  4. Testes

Listas de descrição

As listas de descrição são muitos utilizadas quando precisamos criar glossários, fichas técnicas e perguntas frequentes. Abaixo exemplificamos o seu uso.

WireFrame
Esboço que define a disposição dos elementos, sem cores nem tipografia.
Responsividade
