Introdução ao HTML

O HTML é uma linguagem de marcação que utiliza tags para exibir informações em documentos HTML.

O HTML está na versão cinco e é atualmente o padrão estrutural para criar páginas na internet. Ele funciona como esqueleto de um site, organizando textos, imagens, vídeos, links para que o navegador condiga interpretar e exibir tudo corretamente.

Estrutura de uma página HTML.

Documentos html possuem uma estrutura basilar centrado nas tags: <html> <head> <body>
