Exemplo 32 HTML CSS - Box Model

O Box Model ou modelo de caixa é um dos conceitos mais fundamentais do CSS, pois ele retrata ou dita como um elemento HTML será renderizado na tela, determinando o seu tamanho, espaçamento e como ele interagirá com outros elementos.

O Box Model é dividido em 4 camadas, como se fosse uma caixa, neste exemplo estaremos demonstrando cada uma destas camadas que são:

  1. Content(Conteudo): é o conteúdo real do elemento, como textos, imagens ou videos, dentro outros.
  2. Padding(Preenchimento): é relacionado ao espaço interno entre o conteúdo e a borda da caixa.
  3. Border (Borda): É a linha que envolve o preenchimento e o conteúdo da nossa caixa e pode ser exibida de várias formas.
  4. Margin(Margem): A propriedade margin é o espaço transparente ao redor da caixa, e serve para afastar os elementos uns dos outros.
