Uso dos métodos de Arrays em JavaScript

Os métodos de arrays permitem adicionar, remover, organizar e localizar elementos em uma lista.

push()

Adiciona elementos ao final de um array. Utilizado para incluir novos itens em uma lista.

pop()

Remove o último elemento do array. Utilizado para retirar o item mais recente de uma lista.

sort()

Ordena os elementos do array. Utilizado para organizar nomes, números e outros valores.

indexOf()

Retorna o índice da primeira ocorrência de um elemento. Utilizado para localizar valores em uma lista.

lastIndexOf()

Retorna o índice da última ocorrência de um elemento. Utilizado quando existem valores repetidos no array.
