Exemplo 9 - Links e Tabelas

Descrição

Este exemplo mostra como criar tabelas e links em HTML, nele também utilizamos a estrutura da web semântica , que tem um papel muito importante na indexação de conteúdos pelos mecanismos de busca. Neste exemplo estemos usando as tags semânticas <header>, <footer>, <section>, <nav> e <article>

Também utilizamos as tags para criação dos links e tabelas, que são descritos a seguir:

  • <a>Define um hyperlink
  • <table>Define uma tabela
  • <tr>Define uma linha da tabela - table row
  • <th>Define um cabeçalho da tabela - table header
  • <td>Define uma célula da tabela - table data

Exemplo de links qu abrem uma nova aba:

  • Visite o Google
  • Visite o CNN
  • Explore projetos no GitHub
  • Veja vídeos no YouTube
