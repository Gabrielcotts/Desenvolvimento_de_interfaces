Exemplo 29 HTML - CSS (Estilos aplicados ao texto)

Uma das principais aplicações do CSS é a da estilização de textos, são muitas as propriedades que podem ser utilizadas e aplicadas a um documento HTML. Neste exemplo iremos aplicar algumas delas.

Principais Propriedades de Texto do CSS

A tabela abaixo apresenta algumas das propriedades mais utilizadas para formatação de textos em CSS.

Propriedade O que faz Exemplo
color Altera a cor do texto color: blue;
font-family Define a fonte utilizada no texto font-family: Arial;
font-size Define o tamanho do texto font-size: 20px;
font-weight Define a espessura do texto font-weight: bold;
font-style Permite definir o texto em itálico font-style: italic;
text-align Define o alinhamento do texto text-align: center;
text-decoration Adiciona decoração ao texto, como sublinhado ou riscado text-decoration: underline;
text-transform Transforma o texto em maiúsculas ou minúsculas text-transform: uppercase;
text-indent Define o recuo da primeira linha de um parágrafo text-indent: 40px;
letter-spacing Define o espaço entre as letras letter-spacing: 2px;
word-spacing Define o espaço entre as palavras word-spacing: 5px;
line-height Define o espaçamento entre as linhas do texto line-height: 1.5;
