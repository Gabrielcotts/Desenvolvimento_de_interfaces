Exemplo 31 - HTML CSS (Unidades de medida)

Em CSS podemos utilizar vários tipos de unidades de medida, elas são utilizadas para definir tamanhos de elementos HTML.

Essas unidades de medida são subdivididas em dois grupos: unidades de medida absoluta e relativa.

Unidades de medidas Absolutas

São unidade de medida que tem o tamanho fixo, ou seja, elas não mudam, independente do tamanho da tela ou do monitor.

Unidades de medidas relativas

As unidades de medidas relativas são aquelas em que o tamanho é flexível , ou seja, elas se adaptam com base em outro valor, como largura, altura, tamanho do elemento pai ou tamanho do base da fonte da página.
