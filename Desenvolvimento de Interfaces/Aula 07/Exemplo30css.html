Exemplo 30 HTML - CSS (Cores em CSS)

O CSS permite representar cores de diferentes formas. Podemos utilizar o nome da cor, valores hexadecimais, RGB, RGBA, HSL, HSLA, dentre outros.

1. Cores pelo nome

Uma das formas mais simples de utilizar cores no CSS é informando diretamente na propriedade referente a cor o nome da cor.

Este texte utiliza a cor blue.

2. Cores no padrão hexadecimal

O padrão de cores hexadecimal é aquele que usa o símbolo # seguido normalmente de seis caracteres do sistema hexadecimal que vai do 0 ao 9 e da letra A à F.

Os dois primeiros representam o vermelho, os dois seguintes representam o verde e os dois últimos representam o azul.

Este texto utiliza a cor hexadecimal #8B0000.

Exemplo: color: #8B0000;

3. Padrão de cores RGB

O sistema de cores RGB é aquele baseado nas cores Vermelho(R), Verde(G), Azul(B). Cada uma dessas três cores recebe um valor de 0 a 255, onde o 0 é a aunsência de cor e o 255 todas as cores

Além disso podemos também utilizar um canal de transparência chamado Alfa, ficando o sistema descrito como RGBA, o alfa(A) pode variar entre 0 e 1, onde quanto mais próximo do 0 maior será a transparência e mais próximo do 1 menos transparente será

4. Padrão de cores HSL

O padrão HSL significa HUE, Saturation e Lightness, ou seja, matiz saturação e luminosidade. A matiz representa a posição da cor no círculo cromático e normalmente varia de 0 a 360º. Já a saturação determina a intensidade da cor e é representada por valrores percentuais. Por fim, temos a luminosidade que determina o quanto a cor será clara ou escura e também pe definida por valores perecentuais.
