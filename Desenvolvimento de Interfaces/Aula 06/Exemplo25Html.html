Exemplo 25 HTML CSS - Formas de vinculação de arquivos CSS

Existem 2 formas básicas de vinculação de arquivos CSS em documentos HTML: as formas interna e externa. Neste exemplo, vamos demonstrar a vinculação externa, que é aquela onde criamos ou utilizamos um arquivo CSS externo.

A vinculação externa apresenta uma série de vantagens em relação à vinculação interna de arquivos CSS. Dentre as vantagens, podemos citar:

  • Facilidade de manutenção: isso ocorre pois você edita apenas um arquivo CSS que é aplicado a todos os arquivos que o utilizarem.
  • Reutilização de código: um único código ou arquivo de estilo pode ser ligado a dezenas ou centenas de páginas HTML.
  • Carregamento mais rápido: o navegador guarda em cache o arquivo CSS carregado, o que aumenta a velocidade de carregamento da página HTML.
  • Organização de código: quando utilizamos arquivos CSS externos, eles ficam separados dos arquivos HTML, o que facilita a análise, organização e manutenção destes arquivos.

Vinculação Externa

A vinculação externa é a forma mais recomendada. Neste caso, o arquivo CSS é uma parte do que pode ser criado pelo desenvolvedor ou um arquivo de um grupo, como exemplo o Framework Bootstrap. Neste caso, para vincular o arquivo externo, devemos usar a tag link.

Neste exemplo, estamos usando um arquivo externo para estilizar todos os nossos elementos. Ou seja, nesse arquivo externo temos nossas regras de estilização que serão aplicadas a este documento ou a qualquer outro. É importante frisar que a vinculação externa é a mais recomendada, pois facilita a manutenção e o reuso do arquivo.
